Права пользователей и групп
1. Просмотр списка пользователей
cat /etc/passwd

2. Просмотр паролей 
sudo cat /etc/shadow

3. Просмотр групп
cat /etc/group

4. Просмотр паролей групп
sudo cat /etc/gshadow

5. Создание нового пользователя
sudo useradd -m -s /bin/bash <имя пользователя>

6. Изменение параметров учетной записи
sudo usermod <ключи> <имя пользователя>
sudo usermod -aG <имя группы> <имя пользователя>

sudo chage <ключи> <имя пользователя>

7.Создание новой группы
sudo groupadd <имя группы>

8. Смена членства в группе пользователем
newgrp <имя группы>
Нужно знать пароль или быть заранее включенным в группу администратором 

9. Удаление пользователей и групп
sudo userdel <имя пользователя>
sudo groupdel <имя группы>

10. Просмотр параметров учетной записи
id <имя пользователя>

11. Альтернативный способ получения информации о пользователях и группах 
getent passwd
getent group
