Изменение прав доступа к объектам ФС
1. Изменение владельцев объектов
sudo chown <имя пользователя>:<имя группы> <имя объекта>
sudo chgrp <имя группы>

2. Изменение режима доступа к объектам
sudo chmod 664 <имя объекта>
sudo ugo+rwx <имя объекта> - выдача полных прав доступа на объект
sudo go-w <имя объекта>- удаление права доступа на запись

3. Установка пароля на доступ к группе 
sudo gpasswd <имя группы>

4. Назначение администратора группы
sudo gpasswd -A <имя пользователя> <имя группы>

5. Специальные биты доступа к объектам 
u-bit - назначается только файлам 
g-bit - назначается и файлам и папкам
t-bit - назначается только папкам

Установка u-bit:
sudo chmod u+s <имя файла> - исполнение файла от имени владельца 
Установка g-bit для файла: 
sudo chmod g+s <имя файла> - исполнение файла от имени группы
Установка g-bit для папки:
sudo chmod g+s <имя папки> - наследование группы всеми объектами, создаваемымми внутри папки
Установка t-bit:
sudo chmod o+t <имя папки> - запрет удаления объектов внутри папки, созданных другим владельцем
